# 图表类型体系与选型规则（源自 1.8 节）

> 来源：《R 语言数据可视化之美：专业图表绘制指南（增强版）》（张杰）第 1 章 1.8 节，及全书判断性结论摘录。
> 用途：根据用户的数据形状与分析目的，判断该用哪一类、哪一种图表。
> 所有结论后 `(p.页码)` 为该书印刷页码，回答时应一并给出，便于用户回查原书。

## A. 图表类型体系（1.8 节，p.78–83）

Nathan Yau 的数据可视化四问（选图前的决策链）`(p.78–79)`：你拥有什么样的数据 → 你想表达什么样的数据信息 → 你会什么样的数据可视化方法 → 你从图表中能获得什么信息。
书中按"数据想侧重表达的内容"把图表分为 6 大类：类别比较、数据关系、数据分布、时间序列、局部整体、地理空间。**注意：有些图表也可以归类于两种或多种图表类型。** `(p.78)`

### A1. 类别比较（1.8.1 `(p.79)`）

数据特点：一般包含**数值型 + 类别型**两种数据类型；如柱形图 X 轴为类别型、Y 轴为数值型，采用**位置 + 长度**两种视觉元素。**通常用来比较数据的规模**——可能是相对规模（显示哪一个比较大），也可能是绝对规模（需要显示精确的差异）。

| 图表名 | 何时用 | 何时别用 / 避坑 |
|---|---|---|
| 柱形图 | 比较规模的标准图表；类别数适中、需要精确差异时 | **轴线的起始值必须为 0** `(p.79)`；多分类时不设 position 会序列遮盖 `(p.58)`；**必须先排序**，从大到小、最大放最左 `(p.51)` |
| 条形图 | 类别名称较长、类别数较多时（水平方向），需 `coord_flip()` `(p.45)` | 同柱形图，排序后最大放最上 `(p.51)` |
| 雷达图 | 多指标、需要看轮廓/周期与方向差异（极坐标） | 连续时间段趋势显示不如直角坐标系 `(p.48)` |
| 坡度图 | 两个时间点/两个状态间的变化对比 | —（书中仅列名，未展开） |
| 词云图 | 文本频次型类别数据的规模比较 | 不能用于精确数值比较 |

相关：极坐标下可绘制南丁格尔玫瑰图（极坐标柱形图/堆积柱形图）`(p.46)`；华夫饼图、复合型散点饼图需 `coord_fixed(ratio = 1)` `(p.45)`。

### A2. 数据关系（1.8.2 `(p.81)`）

分为**数值关系型、层次关系型、网络关系型**三种。

**（a）数值关系型**——展示两个或多个变量之间的关系，变量一般都为数值型：

| 图表名 | 何时用 | 避坑 |
|---|---|---|
| 散点图 | 变量 1~3 个时的默认选择 | 数据量大而密集时，用形状（◇○□△）区分系列会很难看清分布 `(p.7)` |
| 气泡图 | 变量 1~3 个，需要用面积承载第三个数值变量（`size=`） | 面积是"较不精确"的视觉暗示 `(p.41)`，慎用精确比较 |
| 曲面图 | 三维 (x, y, z) 数值关系 | ggplot2 不擅长三维，需 `lattice::wireframe()/cloud()` 或 `plot3D::persp3D()` `(p.83)` |

**变量多于 3 个**时改用高维可视化：平行坐标系、矩阵散点图、径向坐标图、星形图、切尔若夫脸谱图 `(p.81)`（平行坐标系用 `GGally::ggparcoord()` `(p.45)`）。
**（b）层次关系型**——着重表达个体之间的**包含**和**从属**两种关系（如公司部门组织结构、洲与国家的包含关系）：节点链接图、树形图、冰柱图、旭日图、圆填充图、矩形树状图 `(p.81)`。
**（c）网络关系型**——不具备层次结构（无自底向上/自顶向下层次）的关系数据，表达的关系更自由复杂：桑基图、和弦图、节点链接图、弧长链接图、蜂箱图 `(p.81)`。

### A3. 数据分布（1.8.3 `(p.82)`）

显示数据集中数值及其出现的**频率或者分布规律**：统计直方图、核密度曲线图、箱形图、小提琴图。

| 图表名 | 何时用 | 避坑 |
|---|---|---|
| 统计直方图 | 最**简单与常见**，又称质量分布图；横轴表示数据类型，纵轴表示分布情况 | 需调 `bins`（书中示例 `bins=30`）`(p.30)` |
| 核密度曲线图 | 需要平滑的分布形态而非分箱计数 | 分箱/带宽会改变结论 |
| 箱形图 | 多组分布对比、带离群点检测；可与抖动散点叠加 | 多分类时须配合 `position_dodge()`，否则序列重叠 `(p.58–59)` |
| 小提琴图 | 需要同时看分布密度形状与汇总 | — |

补充：重复实验数据可在"带误差线的散点图 / 带误差线的柱形图 / 箱形图"之间选择，属于"专业"原则要重点考虑的问题 `(p.8)`。

### A4. 时间序列（1.8.4 `(p.82)`）

强调数据**随时间**的变化规律或趋势；X 轴一般为时序数据，Y 轴为数值型。图表：折线图、面积图、雷达图、日历图、柱形图。

| 图表名 | 何时用 | 避坑 |
|---|---|---|
| 折线图 | **显示时间序列变化趋势的标准方式**，非常适用于**相等时间间隔**下的数据趋势 `(p.82)` | 不等间隔/缺失时间段要谨慎 |
| 面积图 | 强调"量"的累积与总量随时间变化 | 多系列堆叠时底层被遮盖 |
| 雷达图 / 极坐标图 | 时间存在**周期性**（天、周、月、季、年）时用极坐标很合适 `(p.48, p.53)` | 连续时间段趋势的显示不如直角坐标系 `(p.48)` |
| 日历图 | 以"天"为单位的长期序列 | — |
| 柱形图 | 时间点少、强调离散时点数值 | 同 A1 |

时间标尺要求：`scale_×××_date()` 要求变量是 **Date** 格式；`scale_×××_datetime()` 要求 **POSIXct**；`scale_×××_time()` 要求 **hms** 格式 `(p.53)`。

### A5. 局部整体（1.8.5 `(p.82)`）

显示局部组成成分与整体的**占比**信息：饼图、圆环图、旭日图、华夫饼图、矩形树状图。

| 图表名 | 何时用 | 何时别用 |
|---|---|---|
| 饼图 | 呈现部分和整体关系的常见方式；每个扇区的弧长（以及圆心角和面积）大小为其所表示数量的比例 | **很难精确比较不同组成的大小** `(p.82)`；**不要使用多种阴影或颜色的饼图**（分散注意力）`(p.75)`；**数据必须从大到小排序，最大的从 12 点位置开始** `(p.51)` |
| 圆环图 | 中心可放总量标注 | 同饼图，弧长比较更难 |
| 旭日图 | 多层级的局部-整体（层次 + 占比） | 层级过深不可读 |
| 华夫饼图 | 用小方格表达百分比，直观 | 需 `coord_fixed(ratio = 1)` `(p.45)` |
| 矩形树状图 | 类别多、需要同时看占比与层次 | 面积比较不精确 `(p.41)` |

### A6. 地理空间（1.8.6 `(p.83)`）

展示数据中的**精确位置和地理分布规律**：等值区间地图、带气泡的地图、带散点的地图。
位置数据形式：经度（longitude）、纬度（latitude）、邮编等，通常用经纬度描述。

实现路径（书中原样记录）`(p.83)`：
- `ggplot2::geom_path()` / `geom_polygon()` + 地理空间坐标系，`data.frame` 格式数据（书中 1.4 称 DataFrame），绘制不同投影下的世界与国家地图；
- `Baidumap::getBaiduMap()` 下载百度局部地图 → `ggmap::ggmap()` 显示；或 `ggmap::get_map()` 下载 Google 局部地图；
- `tmap` 包使用 `SpatialPointsDataFrame` 格式地理数据，**优势在于可以绘制二维插值地图**。

合规：`《地图管理条例》第十五条`——国家实行地图审核制度，向社会公开的地图应报送有审核权的测绘地理信息行政主管部门审核（景区图、街区图、地铁线路图等简单地图除外）`(p.83)`。

### A7. 绘图包的选择映射（`(p.83)`）

- 主用 **ggplot2 及其拓展包**：`ggrepel`、`ggally`、`ggalluvial` 等；
- **ggplot2 不擅长三维图表**，三维柱形图/散点图/曲面图用 `lattice::wireframe()`、`cloud()`，或 `plot3D::persp3D()`、`hist3D()`、`scatter3D()`、`lines3D()`、`text3D()`、`surf3D()`、`polygon3D()`。
- 三维投影参数：正交投影（orthographic / parallel）与透视投影（perspective），对三维图表美观程度尤为重要 `(p.45–46)`。

## E. 书中金句与反例（原文摘录）

1. **"柱形图是用来比较规模的标准图表（注意：柱形图轴线的起始值必须为 0）。"** `(p.79)`

2. **"不要使用多种阴影或者颜色的柱形图和饼图，因为这样会分散读者直接比较各部分的注意力。可以使用相同的颜色代表同一变量，或者使用单色渐变颜色主题，这样读者可以更好地集中注意力去比较数据。但是可以使用较深的色彩或者不同的颜色强调焦点。"** `(p.75)`

3. **"对于柱形图、条形图和饼图最好对数据先排序后再进行展示。对于柱形图和条形图，把数据从大到小排序，最大的位置放置在最左边或者最上边。而饼图的数据要从大到小排序，最大的从 12 点位置开始。"** `(p.51)`

4. **"饼图是用来呈现部分和整体关系的常见方式……但要注意的是，这类图很难去精确比较不同组成的大小。"** `(p.82)`

5. **"每个图表都应该能不依赖正文而独立存在。"**（"一图抵千言"，A picture is worth a thousand words）`(p.3)`

6. **"Combined or not, each graph should be as simple as possible."**（Robert A. Day，如果一张学术图表包含的数据信息太多，反而让读者难以理解自己所要表达的数据信息）`(p.8)`

7. **"有时只借助形状（如菱形 ◇、圆心 ○、方形 □、三角形 △ 等）区分数据系列，就很难清晰地展示数据的分布规律。"**（数据量多而密集时，只能用颜色丰富表达）`(p.7)`

8. **"国内期刊一般以黑白印刷为主，绘图时需要注意采用不同的线型、标记等对不同曲线进行区分；国外的期刊相对而言以彩色印刷为主，但需要注意颜色的搭配。"** `(p.7)`

9. **"极坐标图可以让用户方便地看到数据在周期、方向上的变化趋势，而对连续时间段的变化趋势的显示则不如直角坐标系。"** `(p.48)`

10. **"identity：不做任何位置调整，该情况在多分类柱形图中不可行，序列间会遮盖，但是在多序列散点图、折线图中可行，不存在遮盖问题。"** `(p.58)`；另："由于 ggplot2 主题设置的内部函数及参数非常多，所以不建议新手直接学习" `(p.56)`；"注意：有些图表也可以归类于两种或多种图表类型" `(p.78)`。
