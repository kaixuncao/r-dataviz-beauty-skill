## C. 颜色运用原理与配色方案（1.7 节，p.62–78）

### C1. 颜色模式

**RGB** `(p.62)`：图像处理中最常用的颜色空间，用于颜色显示和图像处理。24 位图像中每种颜色成分由 0~255 表示（48 位图像范围更大）。三维坐标模型：原点到白色顶点的中轴线是**灰度线**（R=G=B）。
色彩变化 = RGB 最大分量顶点与黄/紫/青顶点的连线；深浅变化 = RGB 顶点和黄/紫/青顶点到中轴线的距离；明暗变化 = 中轴线上点的位置（到原点偏暗、到白色顶点偏亮）。**加色法混色模式**，以 RGB 三色光叠加混色，适合显示器等发光体；绘图软件选色主要通过修改 RGB 三个数值 `(p.62–63)`。

**HSL（色相、饱和度、亮度）** `(p.63)`：基于人眼的颜色模式，普及型设计软件常见。色相 H：色相环上 0°~360°，六大主色按 60° 间隔排列（360°/0° 红、60° 黄、120° 绿、180° 青、240° 蓝、300° 洋红）；饱和度 S：0%~100%，数值越大灰色越少越鲜艳（从理性/灰度到感性/纯色）；亮度 L：0（黑）~100%（白），数值越小越暗。

**HSB / HSV** `(p.63)`：HSB（色相、饱和度、亮度）有时也称 HSV（色相、饱和度、色调）。**比起 RGB，HSL 使用更贴近人类感官直觉的方式描述色彩，可以指导设计者更好地搭配色彩。**

**LUV / CIELUV** `(p.65)`：全称 CIE 1976 (L\*, u\*, v\*)，L\* 亮度、u\*/v\* 色度；由 CIE XYZ 经简单变换得到，**具有视觉统一性**；一般图像 u\*/v\* 取 -100~+100，亮度 0~100。类似色彩空间有 **CIELAB** `(p.65–66)`。

**HSLuv** `(p.66)`：R ggplot2 绘图**默认颜色主题方案**即 HSLuv 颜色空间，相对 HSL 更人性化；把 CIELUV 转换到极坐标系即类似 HSL，拓展后饱和度分量可间隔选择色度；但与 CIELUV LCh 不同（后者部分颜色不能显示，如饱和度高的深黄色）。

```r
# 获取 ggplot2 默认离散颜色主题（HSLuv 空间）（p.66）
gg_color_hue <- function(n) {
  hues = seq(15, 375, length = n + 1)
  hcl(h = hues, l = 65, c = 100)[1:n]
}
```

**Hex 十六进制颜色码** `(p.73)`：前两位 red、中间两位 green、最后两位 blue，并列后以 `#` 开头。纯红 `#FF0000`（R=255, G=0, B=0）；纯绿 `#00FF00`（R=0, G=255, B=0）。

> 说明：书中 1.7 节**未讲解 CMYK 颜色模式**，也**未给出 RGB/HSL/LAB 之间的 R 函数转换方法**（如 `col2rgb()`、`rgb2hsv()` 未出现）；颜色生成涉及的是 `hcl()`（默认主题）`p.66` 与 `colorRampPalette()`（插值）`p.71`。

### C2. 颜色主题搭配原理

**色轮/色相环**（12 色 5 轮，按等距排列原色）`(p.65)`：**单色（monochromatic）**由暗、中、明三种色调组成，没有颜色层次但形成**明暗层次**，设计中效果永远不错；**互补色（complement）**取色轮上直线相对的两色（如红和绿），正式设计中比较少见（强烈对比带来特殊性与不稳定性），但**是最突出的搭配**，想引人注目时或许最佳；**三角形（triad）**以 120° 间隔选 3 色，能使画面生动（低饱和度也如此），**一定要选出一种主色、另两种作辅助色**。
其他搭配方法 `(p.64)`：类似色（analogous）、分裂互补色（split complement）、矩形（rectangle）、正方形（square）；工具：配色网 http://www.peise.net/tools/web 基于 HSL 自动生成高级配色方案。

**三大配色原则（对应数据映射变量类型）——最重要** `(p.70)`：

| 类型 | 原理 | 适用数据 / 例子 |
|---|---|---|
| **单色系（sequential）** | 色相基本相同，**饱和度呈单调递增**变化。有序数据一般从大到小排列，对应颜色亮度逐步增加；**小数值通常用较亮的颜色，大数值通常用较暗的颜色**。可能存在色相不同，但主要特征是从亮到暗的亮度变化 | 有序数值，如地区的人口密度 |
| **双色渐变系（diverging）** | 两个不同色系用于两类情况（如正值与负值），主要强调数据基于**关键中间数值（midpoint）**的级数分布；把中间数值作为中间点用**较亮颜色**表示，两端逐步变化到两个不同色相 | 区间 `[-A,0]`、`[0,A]`、`[A,B]`；如基于某疾病平均死亡率的分布 |
| **多色系（qualitative）** | 数据为非数值情况，不同色系表示不同类别，**尤其是用色相最浅或最暗的颜色强调关键类别**；使用不同色相值表示不同类别或数值差异，亮度不必完全相等但基本差不多 | 类别、特征、时间类的周期性数据；区间 `[A,0,B]` 或 `[A,C,B]`（C 为 mean、medium 等） |

- **圆形分布的多色系（circular color system）**是一类特殊的多色系配色方案（如 Python Seaborn 包的 HLS 颜色主题），**适合时间类的周期性数据**（与小时、天、月、年有关的时序数据）`(p.69)`。
- ColorBrewer 2.0 的原理：通过排列组合实现**二值色系、单色系、双色渐变系和多色系**等颜色主题方案 `(p.69)`。

**单色系与双色渐变系的应用要点** `(p.75–77)`：
- 单色系（柱形图/饼图）：不要使用多种阴影或颜色的柱形图和饼图；**可以使用相同的颜色代表同一变量，或使用单色渐变颜色主题**，让读者集中注意力比较数据；但可以用较深色彩或不同颜色强调焦点。
- 单色系（曲线散点图）：**根据数据系列的数值类别设定，亮度随数值从低到高**；也可省去散点数据标记只留曲线展示规律。
- 双色渐变系（相关系数图）：借助圆圈填充颜色深浅 + 圆圈大小两个视觉暗示，中间白色对应相关系数分界点 0。
- 双色渐变系（时序柱形图/条形图）：中间白色对应温度 0，温度越高红色更深、越低蓝色更深，配合长度视觉暗示。

**透明度** `(p.78)`：颜色透明度是重要参数，**尤其在处理数据系列之间的遮挡问题时特别有效**；也适合于**高密度散点图**，通过颜色深浅观察数据分布。

### C4. 颜色拾取的方法与工具（R 包 / 函数）

**R 基础包自带的 5 个预色调色板** `(p.71)`：`rainbow`、`heat.colors`、`terrain.colors`、`topo.colors`、`cm.colors`；插值生成 n 个颜色值：`colorRampPalette(c("red", "white", "green", , alpha = TRUE))(n)` `(p.71)`。

**RColorBrewer 包** `(p.39, p.67–68, p.74–75)`：经典配色包，Origin 2017、Python Seaborn 等都参考引入；方案分**单色系、多色系、双色渐变系**三大类；源自网站 ColorBrewer 2.0（http://colorbrewer2.org）。离散 `scale_fill_brewer(palette = 'Set1')`；连续 `scale_fill_distiller(palette = "RdYlBu")`、`scale_color_distiller(palette = "Blues")`。**需加载 RColorBrewer 包才能使用 "Reds" 等颜色主题；`direction = 0` 表示颜色从浅到深渐变** `(p.39)`。

**wesanderson 包** `(p.71)`：`wes_palette("Darjeeling1")` 获取离散颜色值（https://github.com/karthik/wesanderson）。

**ggsci 包** `(p.72)`：提供 Nature、Science 等经典期刊推荐的颜色主题方案，**是"推荐使用"而非"投稿必须使用"** `(p.71–72)`；`pal_npg("nrc", alpha = 0.7)(9)`——透明度 0.7 的 Nature 配色，数字可指定数目（https://cran.r-project.org/web/packages/ggsci/vignettes/ggsci.html）。

**viridis 包** `(p.72)`：`scale_fill_viridis(option = "magma", discrete = TRUE)` 得离散颜色值，`discrete = FALSE`（如 `option = "viridis"`）得连续颜色条（https://cran.r-project.org/web/packages/viridis/vignettes/intro-to-viridis.html）。

**其他颜色包** `(p.71)`：`ggthemes`、`ggtech` 也提供新的颜色主题方案。（`scales` 包在本书出现于坐标轴变换 `scales::percent()` `(p.50)`；**`paletteer` 包在第 1 章未出现**。）

**取色器方法** `(p.73)`：PPT 和 AI 软件都有取色器，**R、Excel、Origin 等绘图软件没有取色器**。对 R / Origin：导出 SVG、EPS 矢量图 → AI 打开 → ① 对象(O) → 剪切蒙版(M) → 释放(R)；② 对象(O) → 复合路径(O) → 释放(R)；③ 选择图表元素，用取色器调整"填充"和"描边（边框）"颜色；④ 导出时设定好分辨率。

**配色资源网站**：ColorBrewer 2.0（http://colorbrewer2.org）`(p.67–68)`；配色网高级配色工具（http://www.peise.net/tools/web）`(p.64)`。

### C5. 黑白图表 / 色盲友好 / 纹理区分（原样记录）

- 由于彩色印刷成本高，大部分期刊是非彩色的，往往要求学术图表为**黑白颜色**；若都用彩色图表，有些期刊可能收取额外的彩色出版费用 `(p.7)`。
- 黑白图表中，数据系列的区分主要体现在**数据标记**上，可使用**不同的填充纹理**，或**不同的填充颜色和标记形状** `(p.7)`。
- 国内期刊一般以黑白印刷为主，**绘图时需要注意采用不同的线型、标记等对不同曲线进行区分**；国外期刊以彩色印刷为主，但需注意颜色的搭配 `(p.7)`。
- 当数据系列数据量多而密集时，**只借助形状（菱形 ◇、圆心 ○、方形 □、三角形 △ 等）区分数据系列，很难清晰地展示数据的分布规律**——此时必须用颜色丰富数据表达 `(p.7)`。
- 视觉暗示组合对印刷方式的适配（表 1-6-4 `(p.41)`）：

| 组合 | 数据系列区分程度 | 美观程度 | 印刷适合类型 |
|---|---|---|---|
| (a) 位置 + 方向 | 无法 | 较美 | 黑白 |
| (b) 位置 + 方向 + 饱和度 | 较易 | 较美 | 黑白 |
| (c) 位置 + 方向 + 形状 | 容易 | 较美 | 黑白 |
| (d) 位置 + 方向 + 色相 | 容易 | 很美 | 彩色 |
| (e) 位置 + 方向 + 饱和度 + 形状 | 很容易 | 较美 | 黑白 |
| **(f) 位置 + 方向 + 色相 + 形状** | **很容易** | **很美** | **彩色、黑白** |

- **最优组合是 (f)**：既容易区分数据系列、很美观，又同时适应彩色与黑白两种印刷 `(p.41, p.43)`。当 (f) 采用黑白印刷时，色相视觉暗示会消除，只保留"位置 + 方向 + 形状"（即 (c)），**仍能容易区分数据系列** `(p.41)`。

```r
# (f) 位置 + 方向 + 色相 + 形状（p.43）
ggplot(data = df, aes(x = Time, y = value, fill = variable, shape = variable)) +
  geom_line() +
  geom_point(size = 4, colour = "black") +
  scale_fill_manual(values = c("#FF9641", "#FF5B4E", "#B887C3", "#38C25D")) +
  scale_shape_manual(values = c(21, 22, 23, 24)) +
  theme_classic()

# (e) 位置 + 方向 + 饱和度 + 形状（黑白印刷替代方案）（p.43）
ggplot(data = df, aes(x = Time, y = value, fill = variable, shape = variable)) +
  geom_line() +
  geom_point(size = 4, colour = "black") +
  scale_fill_manual(values = c("grey60", "grey30", "black", "white")) +
  scale_shape_manual(values = c(21, 22, 23, 24)) +
  theme_classic()
```
